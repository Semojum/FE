## 1. v3.0.2 — Review Request FE 15건 + 강제 종료 제보

> v3.0.2 태그는 Windows MSI 빌드 실패로 배포되지 않았고, 내용은 v3.0.3에 함께 실렸다.

### 버그

1. **앱 종료 안됨** ⚠️
   종료 훅이 창 닫기를 붙잡고 `destroy()`를 부르는데 capability에 `core:window:allow-destroy`가 없어 거부됐다. 권한 추가 + 보조 창(반으로 나누기) 정리 + `exit(0)` 폴백.
   *확인*: 편집 중 X 버튼 → 저장 후 창이 닫히고 작업 관리자에 프로세스가 남지 않는지.

2. **mode a 우측에서 한글만 입력 안됨** ⚠️
   격자의 숨은 `<input>`이 `value=''` 제어 컴포넌트라 IME 조합 버퍼가 매 렌더마다 지워졌다(영문은 `keydown` 직행이라 멀쩡했다). 비제어로 전환.
   *확인*: 초안 수정 칸에 한글 타이핑 · 붙여넣기.

3. **앱이 예고 없이 강제 종료 (미저장 편집 유실)** ⚠️
   `tauri-plugin-updater`의 Windows 설치가 `std::process::exit(0)`으로 앱을 죽이는데, 시작할 때마다 `autoInstall`로 설치까지 갔다. `close-requested`를 안 거쳐 저장 플러시도 안 됐다. **시작 시엔 확인만**, 설치는 사용자가 [지금 설치]를 누를 때 저장을 밀어낸 뒤 진행(디자인 V3-05).
   *확인*: 구버전 설치본으로 켜서 업데이트 토스트가 뜨고, 누르기 전엔 앱이 안 꺼지는지. 재현하려면 3.0.0 설치본이 필요하다.

4. **마이페이지 모드 A·C 원본 PDF 렌더링 안됨** ⚠️
   presigned URL 호스트(S3)가 Tauri http 허용 목록에 없어 **데스크톱에서만** 플러그인 단에서 거부됐다. `https://*.s3.ap-northeast-2.amazonaws.com/*` 추가. 실서버(계정 `org0102`)로 URL 200 확인 완료, 데스크톱 실기 미확인.
   *확인*: 마이페이지 → 모드 A·C 파일 클릭 → 원본이 뜨는지.

5. **파일 업로드 직후 "결과가 없습니다"가 잠깐 뜸**
   업로드 응답과 SSE 연결 사이에 `isUploading`·`isStreaming`이 둘 다 false인 구간이 있었다. `isConverting`으로 그 구간도 "분석 중..."으로 덮는다.

6. **mode A 좌측 원본이 잘려 보임**
   PDF를 `width={500}` 고정으로 그려 패널이 좁으면 좌우가 잘렸다(문제 번호가 사라졌다). `ResizeObserver`로 패널 폭에 맞춘다.

### 개선 · 변경

7. **화면 크기 조정 — 32칸이 가로 스크롤 없이**
   여백·간격을 줄이고 기본 창을 `1280×800` → `1440×900`, 최소 `800×600` → `1024×640`으로. 최소 창(1024)에서는 가로 스크롤이 남는다.

8. **앱 이름·로고를 세모점으로** ⚠️
   창 제목·아이콘·화면은 `세모점`, 번들 식별용 `productName`은 `Semojum`(ASCII — 한글이면 WiX MSI 빌드가 깨진다).
   > **주의**: `productName`이 바뀌어 **기존 BrailleMate 설치를 덮어쓰지 않고 나란히 설치**된다. 릴리스 노트에 "제어판에서 이전 BrailleMate 제거 + 옛 바로가기 삭제" 안내 필요.

9. **다운로드 시 저장 폴더 선택** ⚠️
   말없이 기본 다운로드 폴더에 떨어뜨리던 것을 데스크톱에서는 저장 대화상자로. 저장 후 경로를 토스트로 알린다.

10. **선택 블록 강조를 배경색으로**
    선택(원본 대조) = 연한 주황 배경 `#fbe4d3`(테두리 없음), 검토 필요(`is_blocked`) = 크림 배경 `#fdf8e3` + 주황 테두리. 두 상태가 테두리 유무로 갈린다.
    > 리뷰어가 주황을 "AI 생성 블록"으로 읽었으나, 디자인상 주황은 **선택된 블록**이다. AI 생성 여부 상태는 디자인에 없다.

11. **블록 버튼 · 대체 텍스트 버튼을 상단 툴바로**
    우클릭 메뉴에만 있던 것을 결과 패널 상단으로. 왼쪽 `블록 추가 · 위로 · 아래로 · 블록 삭제`, 오른쪽 `대체 텍스트`(대체 초안이 있는 블록에서만 활성). 우클릭 메뉴는 그대로.

12. **탭별 작업 문서명 표기**
    탭 버튼 아래 · `원본 파일` 제목 아래에 문서명. 길면 잘라내고 툴팁으로 전체.

13. **로그인 화면** — 변경 없음. 지적된 화면은 V2 빌드이고 현재 코드는 이미 디자인 V3-01과 같다. 어떤 "정보"를 바꿔야 하는지 리뷰어 확인 필요.

### 빌드 · CI

- CI(`ci.yml`)에 서브모듈 체크아웃이 빠져 있어 `main`이 계속 빨간불이었다 — `submodules: recursive` 추가.
- `productName` 한글 → ASCII 복구로 MSI 빌드 실패 해소.

## 2. v3.0.3 · v3.0.4 — `<!…>` 표식 회색 처리

같은 항목을 3단계로 다듬었다. **최종 규칙은 하나**:

> `<!…>` 모양의 **표식 자체만** 글자색을 `#c8ccd4`로 흐리게 한다.

- **표식만** — 안쪽 내용(`<!점역자주>`~`<!/점역자주>` 사이 설명 글)은 본문이라 건드리지 않는다.
- **글자색만** — 칸 배경은 그대로(칠하면 선택·검토 필요 표시와 섞인다).
- **종류를 안 가린다** — `<!표>`·`<!그림>` 등 무엇이 와도 같다. 목록이 아니라 모양으로 찾는다.
- **모드를 안 가린다** — a·b·c 어디서든.
- 32칸 경계에서 접혀 다음 행으로 넘어가도 이어서 잡는다.
- 닫는 `>`가 40칸 안에 없거나 블록을 넘어가면 표식으로 안 본다 — 우연한 `<!`로 판면이 통째로 회색이 되는 쪽이 더 나쁘다.

> 중간에 범위를 넓혔다가(안쪽 설명까지 + `tn_text` 블록 전체) 되돌린 이력이 있다. **v3.0.4 기준으로 봐야 한다.**

## 3. v3.0.5 — 변환 안정성 · 대조 UX · 화면 밀도

### 버그

14. **변환 중 탭을 떠났다 돌아오면 결과가 사라짐**
    탭을 떠날 때 `jobId`가 비면서 SSE가 끊기는데, 돌아올 때 스냅샷만 되살리고 스트림을 다시 붙이지 않았다. 그래서 떠나 있는 동안 끝난 페이지가 영영 안 오고, 결과 패널이 "결과가 없습니다"로 남았다. 돌아올 때 `attachJob`으로 재연결 + 놓친 페이지는 조회로 채운다.
    *확인*: 변환 중 다른 탭 → 몇 초 뒤 복귀 → 진행률과 결과가 이어지는지.

18. **조합 중인 한글이 격자에 바로 보인다**
    확정돼야 들어가서 `ㄱ`만 친 상태에서는 아무것도 안 보였다. `compositionupdate`마다 조합 중인 글자를 미리 넣고 같은 자리를 갈아 끼운다(`ㄱ` → `가` → `각`). 조합 취소 시 걷어낸다. 조합 중에는 `keydown`을 IME에 넘긴다(Backspace 두 번 먹기·Enter 커서 이동 방지). 점자 6점 키는 영향 없다.

### 개선

15. **원본 ↔ 결과 hover 대응**
    한쪽에 마우스를 얹으면 그쪽만 상자가 떴다. 이제 어느 쪽에 얹든 양쪽 같은 블록에 테두리 상자가 뜬다. **반으로 나누기로 창이 갈려 있어도** 동기화 채널로 대응된다. 검토 필요(주황 상자)가 있으면 그쪽이 우선.

16. **변환 설정을 업로드 직후 모달로 (Figma V3-02)**
    쪽번호·꼬리말을 드롭존 안에 두면 파일 올리기 전이라 그냥 지나치기 쉬웠다. 파일을 고른 직후 [변환 설정] 모달로 묻고, **[변환 시작]을 눌러야 업로드**된다. 점자 판면을 내는 모드(b·c)에만 뜨고, 초안 생성(a)은 종전대로 바로 올린다.

17. **마이페이지 = 자세히 보기 목록 + 미리보기**
    카드 격자 → 윈도우 탐색기식 목록(이름·모드·작성일). 줄을 누르면 오른쪽에 미리보기(썸네일·모드·작성일·쪽 수·위치·상태 + 열기·다운로드). 폴더가 항상 파일보다 앞.
    - 빈 곳 우클릭 → 새 폴더 (툴바 [새 폴더] 버튼 제거)
    - 파일·폴더를 폴더 줄로 끌어 옮기기, 빈 곳에 놓으면 현재 폴더로. 다중 선택은 함께 이동. **변환 중 파일은 안 끌린다**, 폴더를 자기 자신에 넣기는 막힌다.
    - hover ⋯ 버튼 제거 — 우클릭이 같은 메뉴를 연다.

19. **상단 두 줄 → 한 줄, 패널 세로 확장**
    메인 워드마크 제거, 마이페이지·계정·로그아웃·창 분할을 탭 줄 오른쪽으로. 변환 진행률은 결과 패널 안으로. 패널 높이 `600px` 고정 → 남는 세로 공간을 채운다(최소 `420px`).

20. **줄번호 주황 점 제거**
    판면을 어지럽혔다. 대체 텍스트 유무는 상단 [대체 텍스트] 버튼의 활성/비활성으로 알 수 있고, 안내는 줄번호 툴팁으로 남긴다.

- **입력란·출력란 같은 크기** — 출력란만 1.5배로 넓히던 것을 동일 `flex-1`로. 바깥 여백을 줄여 벌충한다.
  > 기본 창 1440에서 격자 가용 폭 660px, 32칸에 필요한 폭 646px — **여유가 14px뿐**이다. 패딩·간격·칸 크기를 키우면 가로 스크롤이 되살아난다.
- **검색 placeholder**를 `검색`으로 줄임(aria-label은 `작업 검색` 유지).
- **이름 정리** — `braillemate` → `semojum`(Cargo 패키지·동기화 채널·결과 창 이름·README). `identifier`(`com.braillemate.app`)는 유지 — 바꾸면 자동 업데이트가 끊긴다.

## 4. 미해결 · 남은 것

21. **다른 페이지 시각자료 데이터가 표기되는 문제** — 재현 자료가 없어 원인 미특정.
    - 페이지 매핑은 `page_done.page_no` 기준이라 섞일 경로가 없다.
    - 요소 id는 UUID로 전역 고유 — 이 경로도 아니다.
    - 대체 초안 피커가 블록 id만으로 전체를 훑던 것은 페이지까지 지정하도록 고쳤다.
    - **필요한 것**: 문제 원본 파일 + jobId + "어느 페이지에서 어느 페이지 자료가 보였는지".

- **디자인 대조에서 나온 미반영 차이** (QA 항목 밖)
  - 헤더 우측은 디자인상 아이콘 2개, 현재는 텍스트 버튼 4개
  - 결과 패널 하단 안내 문구 없음
  - 블록 삭제 후 되돌리기 토스트 없음 (Ctrl+Z는 동작)

- **Windows 실기 확인이 남은 항목**: 1(종료) · 2(한글 입력) · 3(업데이트) · 4(원본 PDF) · 8(설치/이름) · 9(저장 대화상자)
